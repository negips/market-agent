Session Workflow

▶ Every Julia session
1
Load the module
using TijoriData
2
Start the sidecar
TijoriData.start!()
Launches Node.js + Chromium in the background. Wait for the "started on port 3001" message.
3
Use TijoriData normally
search_company("...")  ·  get_overview("...")  ·  get_financials("...", :pl)
4
Stop the sidecar when done
TijoriData.stop!()
Also runs automatically when Julia exits.
⚙ One-off commands
Re-authenticate Tijori session
Run when TijoriData calls start returning errors (session expired)
cd /home/prabal/workstation/git/Agents/sidecar/tijori-finance-mcp && node discover.js --reauth
Update TijoriData after a git pull
using Pkg; Pkg.update("TijoriData")  →  restart Julia
Change sidecar path (if repo moves)
TijoriData.configure!(sidecar_dir="/new/path/to/sidecar")
Call this before start!() in that session.
Check sidecar is reachable
TijoriData.is_running()  # returns true/false
