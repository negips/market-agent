Data availability
OHLCV CSVs on disk, per exchange and bar size.
current (last bar ≤ 3 days old) recent (4–30 days) stale (31–365 days) dormant (> 1 year: delisted or suspended)

Macro series

Generated by julia scripts/ohlcv/scan_ohlcv_availability.jl (about 20 s; reads only the head and tail of each CSV). Row counts are estimates from file size. Age is measured from the scan date, so a symbol that last traded on a Friday shows as current until the following Tuesday.
