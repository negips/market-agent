The model predicts, at every minute, a distribution for the next minute's return: a location (the mean) and a scale. The table is the next vector: for every stock, the predicted next close and its 68% and 95% central intervals against the close that actually followed. The chart also draws the prediction the model made at every earlier minute of the section (each predicts the bar one step ahead; the model is causal, so none of them saw the bar it predicts). A stock that did not trade in the next minute keeps its last close, so a flat actual there is not a hit. Run scripts/forecaster/predict_minute_forecaster.jl (the command above) to change the section; the page reads data/forecast_prediction.json (1 min) or data/forecast_prediction_15min.json (15 min).
Iterated forecast. Each minute is generated from the one before: a return is drawn from the model's predicted distribution, appended to the window, and the model runs again, for independent paths. The model has no target for the overnight move, so when a forecast crosses into a new day its first minute is drawn from that stock's own past overnight gaps, and the bands widen accordingly.
