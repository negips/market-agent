Output
Predictions
(35, B)
35 hourly log-return bars: log(Ph / closeT) for h = 1…35 covering the next 5 trading days.
Loss (training)
weighted MSE + L2
Per-example weight = (peak|log-return| / 4%)² when above threshold — quadratic upweighting of large-move examples. L2 on Dense weight matrices only.
Loss (logged)
pure MSE only
L2 penalty is stripped before logging so train MSE is directly comparable to val MSE (which has no regularization term).
