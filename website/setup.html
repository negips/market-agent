Daily Workflow
▶ Every trading day
1
Get fresh Kite token
node sidecar/kite_login.js
Fully automated — TOTP, login, token saved. ~10s.
2
Start the sidecar
node sidecar/server_http.js
Or let Julia start it automatically via TijoriData.start!()
3
Update OHLCV data
julia --project=packages/StockSwingPredictor scripts/update_ohlcv.jl
Appends only the missing bars since the last run — much faster than a full re-fetch. Use --daily-only to skip hourly.
4
Build inference cache
julia --project=packages/StockSwingPredictor scripts/build_cache.jl
Reads all OHLCV CSVs once → aligned daily + hourly matrices → inference_cache.bson (~42 MB). Loaded into memory at session start for O(1) prediction slices.
5
Refresh NSE data
julia scripts/generate_nse_list.jl
Fetches latest bhavcopy — closing price & market cap for all NSE EQ companies.
6
Run confidence checks (optional — slow)
julia --project=packages/CompanyConfidence scripts/run_confidence_checks.jl 100
Scores top-N companies by market cap. ~6–15s per company via sidecar.
7
Refresh watchlist
julia --project=packages/EarningsCalendar scripts/generate_earnings_watchlist.jl
Merges NSE confirmed events + Tijori projections. Fetches live prices from Kite.
8
Start news monitor daemon (optional)
julia scripts/monitor_news.jl
Polls BSE every 60s + 3 RSS feeds every 5 min. Classifies with Claude Haiku → website/data/news_signals.jsonl. Kill with Ctrl-C; safe to restart.
9
Open the website
./serve.sh
🔄 Every 1–2 weeks
~
Re-authenticate Tijori session
cd sidecar/tijori-finance-mcp && node setup.js
Session cookies expire. Run when sidecar starts returning 403 errors.
~
Enrich earnings dates from Tijori history
julia --project=packages/TijoriData scripts/enrich_earnings_dates.jl
Fetches historical earnings releases per company and projects next expected date via median gap. Resumable — skips already-projected companies. Writes website/data/earnings_projections.json.
